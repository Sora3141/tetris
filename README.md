# TETRIS — SRS Axis Edition

**SRS（スーパーローテーションシステム）**に対応した、本格的な落ち物パズル「テトリス」です。
現代のテトリスに準拠した回転・キック処理を実装しています。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/tetris
- デモ: https://sora3141.github.io/tetris/

## 概要

- 7 種類のテトリミノを落として横一列を消す王道ルール。
- **SRS** 準拠の回転・壁蹴り（ウォールキック）。
- **HOLD** 機能・ネクスト表示。

## 使用技術

- HTML / CSS / Vanilla JavaScript
- **Canvas 2D** による描画

## 操作

| キー | 動作 |
|---|---|
| ←→ | 移動 |
| ↑ / Z・X | 回転 |
| ↓ | ソフトドロップ |
| Space | ハードドロップ |
| Shift / C | ホールド |
